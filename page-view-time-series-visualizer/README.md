# Page View Time Series Visualizer

This project visualizes time series data using Pandas, Matplotlib, and Seaborn.

## 📊 Visualizations Included
- **Line Plot**: Daily page views from May 2016 to December 2019.
- **Bar Plot**: Average monthly page views grouped by year.
- **Box Plots**: Year-wise and month-wise distribution of page views.

## 🧰 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📁 Data Source
Data file: `fcc-forum-pageviews.csv`

## 📌 Key Functions
- `draw_line_plot()`
- `draw_bar_plot()`
- `draw_box_plot()`

## 🧪 Testing
Run `main.py` to test your functions or use `test_module.py` for unit tests.
