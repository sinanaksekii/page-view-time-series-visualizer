# Page View Time Series Visualizer

This project is part of the freeCodeCamp "Data Analysis with Python" certification.

## 📊 Objective
The goal is to visualize time series data using:
- Line Plot
- Bar Plot
- Box Plots

The dataset contains daily page views on the freeCodeCamp forum between 2016-05-09 and 2019-12-03.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📁 Files
- `time_series_visualizer.py`: Contains functions to generate the three plots.
- `main.py`: Used to run and test your functions locally.
- `test_module.py`: Unit tests provided by freeCodeCamp to validate your implementation.
- `requirements.txt`: Required Python packages.
- `fcc-forum-pageviews.csv`: The dataset used for analysis.

## 🖼️ Output Plots
- `line_plot.png`
- `bar_plot.png`
- `box_plot.png`
